# Fonts

Bundled locally so the game works offline and from `file://`.

- IM Fell English (regular, italic), IM Fell English SC, IM Fell Double Pica (regular): Latin subsets.
- Source: the `@fontsource/im-fell-english`, `@fontsource/im-fell-english-sc` and `@fontsource/im-fell-double-pica` npm packages, v5.3.0.
- License: SIL Open Font License 1.1 per the packages' metadata (`OFL.txt`, copied from the packages). Keep that file with the fonts.
